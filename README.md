# 📊 Telegram-бот для учёта личных расходов

Телеграм-бот для учёта личных расходов с возможностью просмотра статистики, создания диаграмм и генерации PDF-отчётов.

## 🚀 Возможности

- ✏️ **Добавление расходов** – введите сумму и выберите категорию или создайте свою
- 📊 **Статистика** – просмотр расходов за день, неделю, месяц, год
- 📈 **Диаграммы** – визуализация распределения расходов по категориям
- 📄 **PDF-отчёты** – генерация детализированных отчётов за любой период
- 🗑 **Управление данными** – очистка статистики за выбранный период
- 🎨 **Удобный интерфейс** – инлайн-кнопки, автоматическое удаление предыдущих сообщений

## 🛠 Библиотеки

- **Python 3.11+**
- **aiogram 3.0** - Асинхронный фреймворк для Telegram Bot API
- **SQLAlchemy 2.0.0** - Хранение данных
- **Matplotlib 3.7.0** - Построение диаграмм
- **ReportLab 4.0.0** - Генерация PDF-отчётов
- **python-dateutil 2.8.0** - Управление конфигурацией
- **numpy 1.24.0** - Числовые вычисления
- **aiosqlite 0.19.0** - Асинхронная SQLite библиотека

## 📋 Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/kuaars/financebot.git
cd financebot
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

4. **Замените токен в файле config.py:**
```env
BOT_TOKEN="ваш_токен_бота из @botfather"
```

5. **Запустите бота:**
```bash
python bot.py
```

## 🎮 Использование

### 🔹 Добавление расхода
1. Введите сумму (например: `250`, `1250.50`)
2. Выберите категорию из списка или создайте свою
3. Расход автоматически сохраняется

### 🔹 Просмотр статистики
1. Нажмите кнопку "📊 Показать статистику"
2. Выберите период: день/неделя/месяц/год
3. Просмотрите список расходов и итоговую сумму
4. Постройте диаграмму или сгенерируйте PDF-отчёт

### 🔹 Генерация PDF-отчёта
- За периоды (день/неделя/месяц/год)

### 🔹 Очистка статистики
1. Выберите "🗑 Очистить статистику"
2. Укажите период для очистки
3. Подтвердите действие

## 🗄 База данных

Бот использует SQLAlcemy для хранения:
- 📌 Пользователей и их профилей
- 💰 Расходов (сумма, категория, дата)
- 📊 Статистики по периодам


## 🐛 Отладка и логирование

- Все действия логируются в консоль с уровнем INFO
- Ошибки автоматически обрабатываются и записываются в логи
- При проблемах с отправкой PDF проверьте права на запись в папке с ботом
