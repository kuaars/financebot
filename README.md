# 🛡️ Менеджер паролей на Python

Настольное приложение для безопасного хранения и управления паролями с шифрованием RSA + AES.  

---

## 🚀 Возможности

- 🔒 **Безопасное хранение паролей** – шифрование RSA + AES-GCM  
- 🗝️ **Мастер-пароль** для доступа к данным  
- ✏️ **Добавление паролей** – возможность сохранять сервис, логин и пароль  
- ⚡ **Генератор паролей** – создаёт сложные и безопасные пароли  
- 👀 **Просмотр и копирование** – расшифровка и копирование пароля в буфер  
- 🗑 **Удаление паролей** – удаление выбранного сервиса  
- 🔄 **Сброс мастер-пароля** – удаляет все данные и ключи  

---

## 🛠 Используемые библиотеки

- **Python 3.10+**  
- **customtkinter** – современный GUI для Tkinter  
- **pyperclip** – работа с буфером обмена  
- **pycryptodome** – шифрование AES  
- **rsa** – шифрование RSA  
- **sqlite3** – хранение паролей в локальной базе

## 📋 Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/yourusername/password-manager.git
cd password-manager
```
2.Установите зависимости:
```bash
pip install customtkinter pyperclip pycryptodome rsa
```
3.Запустите приложение:
```bash
python password_manager.py
```

## 🎮 Использование
🔹 Первый запуск
1. Введите мастер-пароль (не менее 6 символов)
2. При первом запуске ключи RSA создаются автоматически и сохраняются в keys.enc

🔹 Добавление нового пароля
1. Нажмите "Добавить пароль"
2. Введите Сервис, Логин и Пароль
3. Можно сгенерировать пароль автоматически или вставить из буфера
4. Нажмите "Сохранить"

🔹 Просмотр и копирование пароля
1. Выберите сервис из списка
2. Нажмите "Посмотреть"
3. Пароль отобразится, можно нажать "Копировать"

🔹 Удаление пароля
1. Выберите сервис
2. Нажмите "Удалить"
3. Подтвердите удаление

🔹 Сброс мастер-пароля
1. Нажмите "Сбросить пароль" на окне авторизации
2. Все данные будут удалены, приложение перезапустится

## 🔐 Безопасность
- Пароли шифруются с использованием RSA 2048 бит + AES-GCM
- Мастер-пароль не хранится в явном виде
- Все данные хранятся локально:
  - keys.enc – зашифрованные ключи
  - passwords.db – база данных паролей

## 🐛 Отладка и логирование
- Все действия выполняются локально, сеть не используется
